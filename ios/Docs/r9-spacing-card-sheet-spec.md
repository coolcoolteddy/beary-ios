## §1 间距与圆角规范成文（全工程既有口径）

### 1.1 按钮工厂既有口径（BearyButton.swift，B 批已收敛写法、未改视觉）

| 样式 | 高 | 圆角 | 备注 |
| --- | --- | --- | --- |
| primaryPill | 44 | 22 | 墨底反色字，或橙底白字 |
| secondaryOutline regular / compact | 44 / 36 | 22 / 18 | 1pt line 边框 + surface 底 + ink 字 |
| destructiveOutline regular / compact | 44 / 36 | 22 / 18 | 1pt 45% 红边框 + 红字 + surface 底 |
| iconCircleClose | 32×32（视觉） | 16 | faint 底、icon_close 15；热区由父类扩到 44 |

工厂只定视觉，不替调用方下尺寸约束；调用方按 `style.height` 下高约束。
边框色是 CGColor、赋值时固化，深浅切换须经 `refreshChrome()` 重赋。

### 1.2 热区口径（BearyNativeCommon.swift:145-162）

`BearyHit44Button` / `BearyHit44SegmentedControl` 重写 `point(inside:)`：
小于 44 的轴按 `(44 - 边长) / 2` 向两侧扩，已达 44 的轴不扩；不改约束、
不改图标、不改布局，视觉帧一律不动。先在卡片操作行等处配透传栈使用
（见 BearyDiaryCardCell.swift:112-141 的 `BearyActionStackView`），否则扩出
父容器 bounds 的部分会被父级命中测试截掉。

### 2.4 标题行抗压（与 R9-C(2) 验证结论一致）

（`timeLabel`、徽章、皇冠、天气、`moodStack`）均为 `.required`
（860、863-866 行），弹性垫片 `titleSpacerLabel` 横向 hugging /

截断（`numberOfLines = 1`，默认尾部截断）；徽章 / 时间不被挤出。
此为符合设计的行为，无需修（详见 PR 描述的 C(2) 结论）。

## §3 底部面板头部规范成文（只统一成文，不动面板代码）

### 3.1 适用范围

底部升起的 sheet：草稿箱、@ 选人面板、表情面板；邀请页为变体。
全页顶栏（设置页、诊断页、搜索页顶行）不在本节口径内。
本节不逐页换工厂；代码一字不动，偏差逐项列出，待定口径后再施工。

### 3.2 共享 chrome（BearyNativeCommon.swift:59-67，多数派口径）

- Sheet 顶圆角 `topCornerRadius = 20`（仅顶两角）。
- Grabber：宽 40、高 4、顶距 10、圆角 2、颜色 line、居中。
- 遮罩：`scrim` 45%（`scrimAlpha = 0.45`）。
- 采用处：草稿箱 sheet 与把手、@ 面板把手、居中弹窗外框与遮罩、
  SceneDelegate 弹窗遮罩。

### 3.3 成文规范（多数派归纳，记录用）

1. 自上而下：grabber → 标题行 → 内容；标题行内关闭钮为 32 faint
   圆钮（icon_close 15、圆角 16、热区 44，工厂 `iconCircleClose` 或同款手写）。
2. 标题与关闭钮同行居中对齐；标题行高由关闭钮链驱动时为 44
   （32 + 上 6 + 下 6，草稿箱实测）。
3. 内容顶距标题行底 12（@ 面板搜索框、表情面板内容区实测一致）。
4. 左右边距以 16 为多数派（@ 面板、草稿箱关闭右 -14 为近似值）；
   18（表情面板）与 20（消息头，不属面板）单列为偏差。
