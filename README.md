# beary iOS App

beary 是一款个人日记 App：日子值得记得。

用纯原生 Swift / UIKit 写成，与网页版共用同一套账号与日记数据，在 App 里写的日记，网页版也能看到。

## 功能

- 写日记：默认私密，可选公开、仅好友、限时；写完 15 分钟内可以改，删掉的日记 30 天内可以在回收站找回
- 广场、正在关注、时间线、个人页、搜索
- 关注、好友、私信
- 日记盲盒、星图、年度回顾、那年今日、写给过去的自己
- 举报、拉黑
- 不登录也可以浏览公开日记，登录后解锁完整版

## 获取

- 线上日记站：https://teddyhn.com/beary
- iOS 安装包：见本仓库 [Releases](https://github.com/coolcoolteddy/beary-ios/releases)（需要 iOS 15 或更高版本）

## 本地构建（需要 Mac + Xcode）

```sh
git clone https://github.com/coolcoolteddy/beary-ios
```

用 Xcode 打开 `ios/App/App.xcodeproj`，选模拟器或真机，点 ▶ 运行。
